# AAM v1.1

AAM v1.1 is here with a set of quality-of-life improvements, including quoted items in lists, inline objects, relative path resolution, and a built-in formatter.

<!--truncate-->

## What's New in v1.1

### Quoted Items in Lists

List items can now be wrapped in double (`"`) or single (`'`) quotes. Commas inside quoted items are handled correctly — no more false separators:

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

This creates three items: `rust, aam`, `single, quoted`, and `plain_value`. Quotes are automatically stripped from the final values.

### Inline Objects

Values can now be inline objects, making nested configurations more natural:

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

Fields are comma-separated, and nesting `{}` is fully supported.

### Multiline Directives

Multiline support for `@schema`, `@type`, and other directive blocks has been improved. Blocks spanning multiple lines are accumulated and processed correctly, with proper brace-balance tracking:

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### Relative Path Resolution

`@import` and `@derive` paths are now resolved relative to the file they're written in:

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### Built-in Formatter

AAM now includes a formatter that automatically formats your files. It supports smart schema formatting, directive hoisting, configurable indentation, and key sorting.

### AOT Compilation

The new AOT (Ahead-of-Time) compilation path detects simple files and uses a fast single-pass parse, falling back to the full pipeline only when needed for multiline blocks or directives.
