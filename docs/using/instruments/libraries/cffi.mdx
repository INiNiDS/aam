# C FFI API Reference

Source of truth: `include/aam.h`. This API provides a stable C interface for integrating AAM into other languages or systems.

## Handle Lifecycle

| Function | Description |
|:---|:---|
| `AamHandle *aam_new(void)` | Creates a new AAM handle. |
| `void aam_free(AamHandle *handle)` | Frees a previously created handle. |

## Parse and Load

| Function | Description |
|:---|:---|
| `int aam_parse(AamHandle *handle, const char *content)` | Parses AAM content from a string. |
| `int aam_load(AamHandle *handle, const char *path)` | Loads and parses an AAM file from disk. |
| `int aam_format(AamHandle *handle, const char *content)` | Formats AAM content. |

**Return convention:** `0` on success, non-zero on error.

## Lookup

| Function | Description |
|:---|:---|
| `char *aam_get(const AamHandle *handle, const char *key)` | Forward lookup by key. |
| `char *aam_reverse_search(const AamHandle *handle, const char *value)` | Explicit reverse lookup. |
| `char *aam_deep_search(const AamHandle *handle, const char *key)` | Follows recursive references. |

:::important
Returned strings are owned by Rust and must be released via `aam_string_free` to avoid memory leaks.
:::

## Memory and Errors

| Function | Description |
|:---|:---|
| `void aam_string_free(char *s)` | Frees a string returned by any of the lookup functions. |
| `const char *aam_last_error(const AamHandle *handle)` | Returns the last error message as a borrowed string. |

:::warning
`aam_last_error` returns an internal borrowed pointer. **Do not free it.**
:::
