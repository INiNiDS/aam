# Parsing

This page covers all the ways you can load and parse AAM content into your application using official AAM libraries. While examples often focus on Rust and Python, the same principles apply across all supported languages.

---

## Syntax & Parsing Behavior

AAM uses a line-based `key = value` format with some specific parsing rules:

### Comments

The `#` character is used for comments, but **only when surrounded by whitespace**. This allows hex color values (like `tint = #ff6600`) to be parsed correctly without being mistaken for comments.

```aam
# This is a comment
tint = #ff6600  # This is NOT a comment
name = #NoSpaceHere # This is NOT a comment (invalid or literal)
```

### Quotes

String values can optionally be wrapped in double (`"`) or single (`'`) quotes. Quotes are stripped automatically during parsing, and commas inside quoted values are preserved.

```aam
title = "Hello, World!"
items = ["rust, aam", 'single, quoted', plain_value]
```

---

## From a File

The most common entry point is `AAM::load`, which reads an `.aam` file from disk, processes all directives, and returns a ready-to-use `AAM` instance.

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## From a String

Use `AAM::parse` to parse AAM content that is already in memory as a string. Note that `parse` also auto-detects file paths — if the string looks like a path to an existing file, it loads the file instead.

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## Lookups

The primary way to retrieve values is via `get(key)`, which does an O(1) lookup:

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### Reverse Search

To find all keys that hold a specific value:

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### Pattern Search

To find all key-value pairs where the key contains a pattern:

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### Combined Find

Search by key first, then fall back to value matching:

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## Iteration

You can iterate over all key-value pairs without allocating:

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## Directives Processed at Parse Time

All AAM directives are resolved automatically during parsing — you do not need to call any additional method after `load` or `parse`:

| Directive   | Effect                                                                          |
|-------------|---------------------------------------------------------------------------------|
| `@import`   | Loads and merges another `.aam` file inline.                                    |
| `@derive`   | Inherits key-value pairs from another file; child wins on key conflicts.        |
| `@schema`   | Registers a named schema and enables automatic per-field type checking.         |
| `@type`     | Registers a custom type alias for use in schema field declarations.             |

## Error Handling

`AAM::load` and `AAM::parse` both return `Result<AAM, AamlError>`. Always handle errors in production code:

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(errors) => {
        for err in errors {
            match err {
                AamlError::IoError { details, .. } => {
                    eprintln!("Could not read file: {details}");
                }
                AamlError::ParseError { line, content, details, .. } => {
                    eprintln!("Parse error at line {line}: '{content}' — {details}");
                }
                _ => eprintln!("Error: {err}"),
            }
        }
    }
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"Error: {e}")
```

> **Note:** For a full description of every `AamlError` variant, see the [aam-rs API Reference](./aam-rs#aamlerror).
