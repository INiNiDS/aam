# AAM v1.1

AAM v1.1 приносит множество улучшений качества жизни: кавычки в списках, inline-объекты, относительные пути для импорта и встроенный форматтер.

<!--truncate-->

## Что нового в v1.1

### Кавычки в списках

Элементы списков теперь можно оборачивать в двойные (`"`) или одинарные (`'`) кавычки. Запятые внутри кавычек обрабатываются корректно:

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### Inline-объекты

Значения теперь могут быть inline-объектами:

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### Многострочные директивы

Улучшена обработка `@schema`, `@type` и других блоков, занимающих несколько строк:

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### Относительные пути

Пути в `@import` и `@derive` теперь разрешаются относительно файла:

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### Встроенный форматтер

Форматтер автоматически форматирует файлы: умное сворачивание схем, поднятие директив, настраиваемые отступы.
