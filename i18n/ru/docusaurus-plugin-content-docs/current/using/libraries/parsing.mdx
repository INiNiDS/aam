# Разбор

Эта страница охватывает все способы загрузки и разбора содержимого AAM в вашем приложении с помощью официальных библиотек AAM. Хотя примеры часто фокусируются на Rust и Python, те же принципы применимы ко всем поддерживаемым языкам.

---

## Синтаксис и поведение парсера

AAM использует построчный формат `ключ = значение` со специфическими правилами разбора:

### Комментарии

Символ `#` используется для комментариев, но **только если он окружен пробелами**. Это позволяет правильно разбирать значения шестнадцатеричных цветов (например, `tint = #ff6600`), не принимая их за комментарии.

```aam
# Это комментарий
tint = #ff6600  # Это НЕ комментарий
name = #NoSpaceHere # Это НЕ комментарий (неверно или литерал)
```

### Кавычки

Строковые значения могут быть опционально заключены в двойные (`"`) или одинарные (`'`) кавычки. Кавычки удаляются автоматически во время разбора.

## Из файла

Наиболее распространённая точка входа — `AAM::load`, которая читает файл `.aam` с диска, обрабатывает все директивы и возвращает готовый к использованию экземпляр `AAM`.

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## Из строки

Используйте `AAM::parse` для разбора содержимого AAM, которое уже находится в памяти в виде строки. Это полезно для встроенных конфигураций, юнит-тестов или содержимого, полученного из удалённого источника.

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap().as_str(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## Поиск (Lookups)

Основной способ получения значений — `get(key)`, который выполняет поиск за O(1):

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### Обратный поиск

Чтобы найти все ключи, содержащие определённое значение:

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### Поиск по шаблону

Чтобы найти все пары ключ-значение, где ключ содержит шаблон:

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### Комбинированный поиск

Сначала поиск по ключу, затем по значению:

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## Итерация

Вы можете перебирать все пары ключ-значение без выделения дополнительной памяти:

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## Директивы, обрабатываемые при разборе

Все директивы AAM разрешаются автоматически во время разбора — вам не нужно вызывать какие-либо дополнительные методы после `load` или `parse`:

| Директива | Эффект |
|-----------|--------|
| `@import` | Загружает и сливает другой `.aam`-файл встроенно. |
| `@derive` | Наследует пары ключ-значение из другого файла; дочерний побеждает при конфликтах ключей. |
| `@schema` | Регистрирует именованную схему и включает автоматическую проверку типов по полям. |
| `@type` | Регистрирует псевдоним пользовательского типа для использования в объявлениях полей схем. |

## Обработка ошибок

`AAM::load` и `AAM::parse` возвращают `Result<AAM, AamlError>`. Всегда обрабатывайте ошибки в производственном коде:

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(AamlError::IoError(e)) => {
        eprintln!("Не удалось прочитать файл: {e}");
    }
    Err(AamlError::ParseError { line, content, details }) => {
        eprintln!("Ошибка разбора в строке {line}: '{content}' — {details}");
    }
    Err(AamlError::SchemaValidationError { schema, field, type_name, details }) => {
        eprintln!("Схема '{schema}': поле '{field}' ({type_name}) — {details}");
    }
    Err(e) => eprintln!("Неожиданная ошибка: {e}"),
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"Ошибка: {e}")
```

> **Примечание:** Полное описание каждого варианта `AamlError` см. в [справочнике API aam-rs](./aam-rs#aamlerror).
