# AAM v1.1

AAM v1.1 traz melhorias de qualidade de vida: itens entre aspas em listas, objetos inline, resolução de caminhos relativos e um formatador integrado.

<!--truncate-->

## Novidades no v1.1

### Itens Entre Aspas em Listas

Os itens de lista podem agora ser envolvidos por aspas duplas (`"`) ou simples (`'`). Vírgulas dentro de itens entre aspas são corretamente tratadas:

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### Objetos Inline

Os valores podem agora ser objetos inline:

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### Diretivas Multilinha

O tratamento de blocos `@schema`, `@type` e outros que ocupam várias linhas foi melhorado:

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### Caminhos Relativos

Os caminhos em `@import` e `@derive` são agora resolvidos relativamente ao ficheiro:

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### Formatador Integrado

O formatador formata automaticamente os ficheiros: colapso inteligente de schemas, elevação de diretivas, indentação configurável.
