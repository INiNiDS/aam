# Análise (Parsing)

Esta página cobre todas as formas de carregar e analisar conteúdo AAM na sua aplicação usando as bibliotecas oficiais da AAM. Embora os exemplos enfoquem frequentemente o Rust e o Python, os mesmos princípios aplicam-se a todos as linguagens suportadas.

---

## Sintaxe e Comportamento do Parser

O AAM utiliza um formato de linha `chave = valor` com algumas regras de análise específicas:

### Comentários

O carácter `#` é utilizado para comentários, mas **apenas quando rodeado por espaços em branco**. Isto permite que os valores de cor hexadecimais (como `tint = #ff6600`) sejam analisados corretamente sem serem confundidos com comentários.

```aam
# Isto é um comentário
tint = #ff6600  # Isto NÃO é um comentário
name = #NoSpaceHere # Isto NÃO é um comentário (inválido ou literal)
```

### Aspas

Os valores de string podem ser opcionalmente envolvidos por aspas duplas (`"`) ou simples (`'`). As aspas são removidas automaticamente durante a análise.

---

## A partir de um Ficheiro

O ponto de entrada mais comum é `AAM::load`, que lê um ficheiro `.aam` do disco, processa todas as diretivas e retorna uma instância `AAM` pronta a usar.

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## A partir de uma String

Use `AAM::parse` para analisar conteúdo AAM que já está em memória como uma string. Isto é útil para configurações inline, testes unitários ou conteúdo obtido de uma fonte remota.

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap().as_str(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## Pesquisas (Lookups)

A forma principal de recuperar valores é através de `get(key)`, que faz uma pesquisa O(1):

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### Pesquisa Inversa

Para encontrar todas as chaves que contêm um valor específico:

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### Pesquisa por Padrão

Para encontrar todos os pares chave-valor onde a chave contém um padrão:

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### Pesquisa Combinada

Pesquisa primeiro por chave e depois por valor:

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## Iteração

Pode iterar sobre todos os pares chave-valor sem alocar memória adicional:

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## Diretivas Processadas em Tempo de Análise

Todas as diretivas AAM são resolvidas automaticamente durante a análise — não precisa de chamar nenhum método adicional após `load` ou `parse`:

| Diretiva | Efeito |
|----------|--------|
| `@import` | Carrega e funde outro ficheiro `.aam` inline. |
| `@derive` | Herda pares chave-valor de outro ficheiro; o filho vence em conflitos de chave. |
| `@schema` | Regista um schema nomeado e ativa a verificação de tipo automática por campo. |
| `@type` | Regista um alias de tipo personalizado para uso em declarações de campo de schema. |

## Tratamento de Erros

`AAM::load` e `AAM::parse` retornam ambos `Result<AAM, AamlError>`. Trate sempre os erros em código de produção:

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(AamlError::IoError(e)) => {
        eprintln!("Não foi possível ler o ficheiro: {e}");
    }
    Err(AamlError::ParseError { line, content, details }) => {
        eprintln!("Erro de análise na linha {line}: '{content}' — {details}");
    }
    Err(e) => eprintln!("Erro inesperado: {e}"),
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"Erro: {e}")
```

> **Nota:** Para uma descrição completa de cada variante `AamlError`, consulte a [Referência de API aam-rs](./aam-rs#aamlerror).
