# 类型

## 基本类型
AAM 具有几种内置基本类型：`string`、`i32`、`f64`、`bool` 和 `color`（接受十六进制颜色代码）。

```aam
@schema User {
    name: string
    age: i32
    is_admin: bool
    profile_color: color
}
```

## 其他内置类型

### 物理类型
使用 `types::physics` 命名空间：
```aam
@schema PhysicsObject {
    length: types::physics::meter
}
```
完整列表见[扩展类型文档](../types/physics)。

### 数学类型
使用 `types::math` 命名空间：
```aam
@schema MathObjects {
    vector: types::math::vector2
}
```
完整列表见[扩展类型文档](../types/math)。

### 时间
datetime 和 duration 使用 ISO 8601 格式：
```aam
@schema TimeObjects {
    timestamp: types::time::datetime
    cooldown: types::time::duration
    units: types::time::hour
}
```
完整列表见[扩展类型文档](../types/time)。

### 列表
```aam
@schema Inventory {
    items: list<string>
}
```
创建列表：
```aam
items = ["Hello", "World"]
```

### 列表中的引号项
列表项可以用双引号（`"`）或单引号（`'`）包裹。引号内的逗号会正确处理，不会被当作分隔符：
```aam
fruits = ["apple, banana", 'orange, grape', plain]
```
这将创建一个包含三项的列表：`apple, banana`、`orange, grape` 和 `plain`。
引号会在解析时自动去除，您可以自由混合使用带引号和不带引号的项目。

### 内联对象
AAM 还支持使用 `{ key = value }` 语法将内联对象作为值。字段之间用逗号分隔：
```aam
config = { host = "localhost", port = 8080, debug = true }
```
内联对象可以嵌套：
```aam
server = { base = { host = "localhost", port = 8080 }, tls = true }
```
您可以通过 `as_object()` 访问内联对象的字段，该方法返回一个键值映射。

## 自定义类型

### 模式
```aam
@schema User {
    name: string
    age: i32
}

@schema ServerUsers {
    users: list<User>
}
```

### 自定义类型声明
使用 `@type` 指令：
```aam
@type Name = string
@type FromLast = types::time::duration
@type FirstName = Name
@type LastName = Name
```
