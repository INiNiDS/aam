# 入门指南
这是 AAM 的快速入门教程，涵盖基础知识，展示如何创建简单的双向映射。

## MVP
AAM 的**最小可行产品**（MVP）只有一行：
```aam
a = b
```
该语法创建了 `a` 和 `b` 之间的双向映射。简洁、清晰，消除了样板代码。
## 语法标准
AAM 遵循简洁的最小化语法，注重可读性和简单性。

### 键值映射
`=` 运算符两侧各需要一个空格：
```aam
a = b
```

### 语句终止
语句以**换行符**终止，无需分号：
```aam
a = b
c = d
e = f
```

### 注释
单行注释使用 `#` 前缀：
```aam
# 这是一条注释
a = b
```

### 指令
指令使用 `@` 前缀：
```aam
@import other-file.aam
```

### 内联模式
```aam
@schema Player {name: string, id: i32}
```

### 多行模式
```aam
@schema Player {
    name: string
    id: i32
}
```

### 命名规范

* 变量和映射使用 snake_case：
    ```aam
    player_score = current_points
    ```

* 内置类型使用 snake_case（如 i32、string、bool）。

* 用户定义类型和模式使用 PascalCase：
    ```aam
    @schema PlayerData { ... }
    @type UserProfile = string
    ```

### 内联对象
值可以使用 `{ key = value }` 语法作为内联对象：
```aam
server = { host = "localhost", port = 8080, debug = true }
```
支持嵌套对象：
```aam
config = { database = { host = "db.local", port = 5432 }, cache = { ttl = 3600 } }
```

### 引号字符串
值和列表项可以用双引号（`"`）或单引号（`'`）包裹。当值包含逗号或特殊字符时尤其有用：
```aam
title = "你好，世界！"
items = ["rust, aam", 'single, quoted', plain_value]
```
引号在解析时自动去除，引号字符串内支持转义序列（`\\`）。

### 格式化工具
AAM 包含内置格式化工具，可自动格式化 AAM 文件。支持：
- **智能模式格式化** — 小模式压缩为单行，大模式展开为多行
- **指令提升** — 将 `@import` 和 `@derive` 指令移至文档顶部
- **可配置缩进** — 制表符 vs 空格、缩进大小、行宽
- **键排序和空行保留**
