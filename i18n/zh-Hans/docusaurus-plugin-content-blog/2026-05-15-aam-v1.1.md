# AAM v1.1

AAM v1.1 带来了多项质量改进：列表中的引号项、内联对象、相对路径解析和内置格式化工具。

<!--truncate-->

## v1.1 新特性

### 列表中的引号项

列表项现在可以用双引号（`"`）或单引号（`'`）包裹。引号内的逗号会正确处理：

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### 内联对象

值现在可以是内联对象：

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### 多行指令

改进了对 `@schema`、`@type` 等跨越多行的指令块的处理：

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### 相对路径

`@import` 和 `@derive` 中的路径现在相对于文件解析：

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### 内置格式化工具

格式化工具可自动格式化文件：智能模式折叠、指令提升、可配置缩进。
