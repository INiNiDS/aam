# AAM v1.1

AAM v1.1 apporte des améliorations de qualité de vie : éléments entre guillemets dans les listes, objets en ligne, résolution de chemins relatifs et un formateur intégré.

<!--truncate-->

## Nouveautés de v1.1

### Éléments Entre Guillemets dans les Listes

Les éléments de liste peuvent désormais être entourés de guillemets doubles (`"`) ou simples (`'`). Les virgules à l'intérieur d'éléments entre guillemets sont correctement traitées :

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### Objets en Ligne

Les valeurs peuvent maintenant être des objets en ligne :

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### Directives Multilignes

La gestion des blocs `@schema`, `@type` et autres s'étendant sur plusieurs lignes a été améliorée :

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### Chemins Relatifs

Les chemins dans `@import` et `@derive` sont désormais résolus relativement au fichier :

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### Formateur Intégré

Le formateur met automatiquement en forme les fichiers : collapse intelligent des schémas, remontée des directives, indentation configurable.
