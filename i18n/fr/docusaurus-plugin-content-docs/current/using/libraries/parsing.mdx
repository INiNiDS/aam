# Analyse (Parsing)

Cette page couvre toutes les manières de charger et d'analyser du contenu AAM dans votre application en utilisant les bibliothèques officielles AAM. Bien que les exemples se concentrent souvent sur Rust et Python, les mêmes principes s'appliquent à tous les langages supportés.

---

## Syntaxe et Comportement du Parser

AAM utilise un format de ligne `clé = valeur` avec quelques règles d'analyse spécifiques :

### Commentaires

Le caractère `#` est utilisé pour les commentaires, mais **seulement lorsqu'il est entouré d'espaces blancs**. Cela permet aux valeurs de couleur hexadécimales (comme `tint = #ff6600`) d'être analysées correctement sans être confondues avec des commentaires.

```aam
# Ceci est un commentaire
tint = #ff6600  # Ceci n'est PAS un commentaire
name = #NoSpaceHere # Ceci n'est PAS un commentaire (invalide ou littéral)
```

### Guillemets

Les valeurs de chaîne peuvent éventuellement être entourées de doubles guillemets (`"`) ou de simples guillemets (`'`). Les guillemets sont supprimés automatiquement lors de l'analyse.

---

## Depuis un Fichier

Le point d'entrée le plus courant est `AAM::load`, qui lit un fichier `.aam` depuis le disque, traite toutes les directives et retourne une instance `AAM` prête à l'emploi.

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## Depuis une Chaîne

Utilisez `AAM::parse` pour analyser du contenu AAM qui est déjà en mémoire sous forme de chaîne. C'est utile pour les configurations inline, les tests unitaires ou le contenu récupéré depuis une source distante.

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap().as_str(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## Recherches (Lookups)

La principale façon de récupérer des valeurs est via `get(key)`, qui effectue une recherche en O(1) :

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### Recherche Inverse

Pour trouver toutes les clés qui contiennent une valeur spécifique :

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### Recherche par Motif

Pour trouver toutes les paires clé-valeur dont la clé contient un motif :

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### Recherche Combinée

Recherche d'abord par clé, puis par valeur :

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## Itération

Vous pouvez itérer sur toutes les paires clé-valeur sans allouer de mémoire supplémentaire :

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## Directives Traitées au Moment de l'Analyse

Toutes les directives AAM sont résolues automatiquement pendant l'analyse — vous n'avez pas besoin d'appeler de méthode supplémentaire après `load` ou `parse` :

| Directive | Effet |
|-----------|-------|
| `@import` | Charge et fusionne un autre fichier `.aam` inline. |
| `@derive` | Hérite des paires clé-valeur d'un autre fichier ; l'enfant gagne sur les conflits de clé. |
| `@schema` | Enregistre un schéma nommé et active la vérification de type automatique par champ. |
| `@type` | Enregistre un alias de type personnalisé pour utilisation dans les déclarations de champ de schéma. |

## Gestion des Erreurs

`AAM::load` et `AAM::parse` retournent tous deux `Result<AAM, AamlError>`. Gérez toujours les erreurs dans le code de production :

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(AamlError::IoError(e)) => {
        eprintln!("Impossible de lire le fichier : {e}");
    }
    Err(AamlError::ParseError { line, content, details }) => {
        eprintln!("Erreur d'analyse à la ligne {line} : '{content}' — {details}");
    }
    Err(e) => eprintln!("Erreur inattendue : {e}"),
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"Erreur : {e}")
```

> **Remarque :** Pour une description complète de chaque variante `AamlError`, consultez la [Référence API aam-rs](./aam-rs#aamlerror).
