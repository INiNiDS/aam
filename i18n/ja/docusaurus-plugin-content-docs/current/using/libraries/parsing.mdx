# パース (Parsing)

このページでは、公式の AAM ライブラリを使用して AAM コンテンツをアプリケーションにロードおよびパースするためのすべての方法を網羅しています。例では Rust や Python が多く使用されていますが、サポートされているすべての言語で同じ原則が適用されます。

---

## 構文とパーサーの動作

AAM は、特定のパースルールを持つ行ベースの `キー = 値` 形式を使用します：

### コメント

`#` 文字はコメントに使用されますが、**空白に囲まれている場合にのみ**有効です。これにより、16進数のカラー値（例： `tint = #ff6600`）をコメントと混同することなく正しくパースできます。

```aam
# これはコメントです
tint = #ff6600  # これはコメントではありません
name = #NoSpaceHere # これはコメントではありません（無効またはリテラル）
```

### 引用符

文字列値は、オプションで二重引用符 (`"`) または一重引用符 (`'`) で囲むことができます。引用符は解析中に自動的に除去されます。

---

## ファイルから

最も一般的なエントリーポイントは `AAM::load` で、ディスクから `.aam` ファイルを読み取り、すべてのディレクティブを処理し、すぐに使用できる `AAM` インスタンスを返します。

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## 文字列から

すでにメモリ内に文字列としてあるAAMコンテンツをパースするには `AAM::parse` を使用します。これはインライン設定、ユニットテスト、またはリモートソースから取得したコンテンツに便利です。

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap().as_str(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## ルックアップ

値の取得方法は、O(1)のルックアップを行う `get(key)` が基本です：

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### 逆引き検索

特定の値を持つすべてのキーを見つけるには：

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### パターン検索

キーにパターンが含まれるすべてのキーと値のペアを見つけるには：

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### 複合検索

最初にキーで検索し、見つからない場合は値で検索します：

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## イテレーション

メモリを追加で割り当てることなく、すべてのキーと値のペアを反復処理できます：

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## パース時に処理されるディレクティブ

すべてのAAMディレクティブはパース中に自動的に解決されます — `load` または `parse` 後に追加のメソッドを呼び出す必要はありません：

| ディレクティブ | 効果 |
|-------------|------|
| `@import` | 別の `.aam` ファイルをインラインで読み込みマージします。 |
| `@derive` | 別のファイルからキーと値のペアを継承します；キーの競合ではchildが勝ちます。 |
| `@schema` | 名前付きスキーマを登録し、フィールドごとの自動型チェックを有効にします。 |
| `@type` | スキーマフィールド宣言で使用するカスタム型エイリアスを登録します。 |

## エラーハンドリング

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(AamlError::IoError(e)) => {
        eprintln!("ファイルを読み取れませんでした: {e}");
    }
    Err(AamlError::ParseError { line, content, details }) => {
        eprintln!("{}行目でパースエラー: '{}' — {}", line, content, details);
    }
    Err(e) => eprintln!("予期しないエラー: {e}"),
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"エラー: {e}")
```
