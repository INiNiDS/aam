# AAM v1.1

AAM v1.1 では、リスト内の引用符付きアイテム、インラインオブジェクト、相対パス解決、組み込みフォーマッターなど、品質向上の改善が多数含まれています。

<!--truncate-->

## v1.1 の新機能

### リスト内の引用符付きアイテム

リストアイテムを二重引用符（`"`）または一重引用符（`'`）で囲めるようになりました。引用符内のカンマは正しく処理されます：

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### インラインオブジェクト

値としてインラインオブジェクトが使えるようになりました：

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### 複数行ディレクティブ

`@schema`、`@type` などの複数行ブロックの処理が改善されました：

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### 相対パス解決

`@import` と `@derive` のパスがファイル相対で解決されるようになりました：

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### 組み込みフォーマッター

スマートスキーマフォーマット、ディレクティブの先頭移動、設定可能なインデントを備えたフォーマッターが搭載されました。
