# AAM v1.1

AAM v1.1 trae mejoras de calidad de vida: elementos entre comillas en listas, objetos en línea, resolución de rutas relativas y un formateador integrado.

<!--truncate-->

## Novedades en v1.1

### Elementos entre Comillas en Listas

Los elementos de lista ahora se pueden envolver entre comillas dobles (`"`) o simples (`'`). Las comas dentro de elementos entre comillas se manejan correctamente:

```aam
items = ["rust, aam", 'single, quoted', plain_value]
```

### Objetos en Línea

Los valores ahora pueden ser objetos en línea:

```aam
server = { host = "localhost", port = 8080, debug = true }
config = { database = { host = "db.local", port = 5432 } }
```

### Directivas Multilínea

Se ha mejorado el manejo de bloques `@schema`, `@type` y otros que ocupan varias líneas:

```aam
@schema Player {
    name: string
    score: i32
    tags: list<string>
}
```

### Rutas Relativas

Las rutas en `@import` y `@derive` ahora se resuelven relativas al archivo:

```aam
@import ./schemas/base.aam
@derive ./types/player.aam::Player
```

### Formateador Integrado

El formateador da formato automático a los archivos: colapsado inteligente de esquemas, elevación de directivas, sangría configurable.
