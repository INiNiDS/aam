# Análisis (Parsing)

Esta página cubre todas las formas de cargar y analizar contenido AAM en tu aplicación usando las librerías oficiales de AAM. Aunque los ejemplos a menudo se centran en Rust y Python, los mismos principios se aplican a todos los lenguajes soportados.

---

## Sintaxis y Comportamiento del Parser

AAM usa un formato de línea `clave = valor` con algunas reglas de análisis específicas:

### Comentarios

El carácter `#` se usa para comentarios, pero **solo cuando está rodeado de espacios en blanco**. Esto permite que los valores de color hexadecimales (como `tint = #ff6600`) se analicen correctamente sin ser confundidos con comentarios.

```aam
# Esto es un comentario
tint = #ff6600  # Esto NO es un comentario
name = #NoSpaceHere # Esto NO es un comentario (inválido o literal)
```

### Comillas

Los valores de string pueden ser opcionalmente envueltos en comillas dobles (`"`) o simples (`'`). Las comillas se eliminan automáticamente durante el análisis.

---

## Desde un Fichero

El punto de entrada más común es `AAM::load`, que lee un fichero `.aam` del disco, procesa todas las directivas y retorna una instancia `AAM` lista para usar.

```rust
use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
```

```python
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))
```

## Desde una String

Usa `AAM::parse` para analizar contenido AAM que ya está en memoria como una string. Esto es útil para configuraciones inline, pruebas unitarias o contenido obtenido de una fuente remota.

```rust
use aam_rs::aam::AAM;

let source = "host = localhost\nport = 8080";
let cfg = AAM::parse(source).unwrap();

assert_eq!(cfg.get("host").unwrap().as_str(), "localhost");
```

```python
from aam_py import AAM

source = "host = localhost\nport = 8080"
cfg = AAM.parse(source)

assert cfg.get("host") == "localhost"
```

## Búsquedas (Lookups)

La forma principal de recuperar valores es mediante `get(key)`, que realiza una búsqueda O(1):

```rust
use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();
let host = cfg.get("host");          // Some("localhost")
let missing = cfg.get("unknown");    // None
```

```python
from aam_py import AAM

cfg = AAM.parse("host = localhost")
host = cfg.get("host")      # "localhost"
missing = cfg.get("unknown") # None
```

### Búsqueda Inversa

Para encontrar todas las claves que contienen un valor específico:

```rust
let keys: Vec<&str> = cfg.reverse_search("localhost");
```

```python
keys: list[str] = cfg.reverse_search("localhost")
```

### Búsqueda por Patrón

Para encontrar todos los pares clave-valor donde la clave contiene un patrón:

```rust
let pairs: Vec<(&str, &str)> = cfg.deep_search("host");
```

```python
pairs: dict[str, str] = cfg.deep_search("host")
```

### Búsqueda Combinada

Busca primero por clave y luego por valor:

```rust
let pairs: Vec<(&str, &str)> = cfg.find("query");
```

## Iteración

Puedes iterar sobre todos los pares clave-valor sin necesidad de asignar memoria adicional:

```rust
for (key, value) in &cfg {
    println!("{key} = {value}");
}
```

```python
for key, value in cfg.to_dict().items():
    print(f"{key} = {value}")
```

## Directivas Procesadas en Tiempo de Análisis

Todas las directivas AAM se resuelven automáticamente durante el análisis — no necesitas llamar a ningún método adicional después de `load` o `parse`:

| Directiva | Efecto |
|-----------|--------|
| `@import` | Carga y fusiona otro fichero `.aam` inline. |
| `@derive` | Hereda pares clave-valor de otro fichero; el hijo gana en conflictos de clave. |
| `@schema` | Registra un schema con nombre y activa la comprobación de tipo automática por campo. |
| `@type` | Registra un alias de tipo personalizado para uso en declaraciones de campo de schema. |

## Gestión de Errores

`AAM::load` y `AAM::parse` retornan ambos `Result<AAM, AamlError>`. Siempre gestiona los errores en código de producción:

```rust
use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => {
        println!("host = {}", cfg.get("host").unwrap());
    }
    Err(AamlError::IoError(e)) => {
        eprintln!("No se pudo leer el fichero: {e}");
    }
    Err(AamlError::ParseError { line, content, details }) => {
        eprintln!("Error de análisis en línea {line}: '{content}' — {details}");
    }
    Err(e) => eprintln!("Error inesperado: {e}"),
}
```

```python
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
    print("host =", cfg.get("host"))
except AamlError as e:
    print(f"Error: {e}")
```

> **Nota:** Para una descripción completa de cada variante `AamlError`, consulte la [Referencia de API aam-rs](./aam-rs#aamlerror).
