aam-rs API Reference

aam-rs is the official Rust library for parsing, validating, and building AAM configuration files. It supports directives (@import, @derive, @schema, @type), schema-based type validation, bidirectional lookup, deep pattern search, and incremental formatting via a multi-stage pipeline.

AAM is the unified struct for all operations — parsing, loading, lookups, formatting, and schema introspection.

Architecture​

The project is designed with a modular architecture:

  • aam/: Unified entry point (AAM struct) for all operations.
  • pipeline/: A five-stage pipeline (Lexer, Parser, Validator, Executer, Formatter).
  • commands/: Directive system (@import, @derive, etc.).
  • builder/: Fluent API for programmatic .aam generation.
  • aot/: Support for "cooked" binary caches (.aam.bin) for fast startup.
  • error/: Structured error types with diagnostic guidance.

Feature Flags​

FlagEffect
hash-stdDefault pipeline hasher (std::collections::hash_map::RandomState)
hash-fx / hash-ahash / hash-rapidhash / hash-ripemdAlternate pipeline hashers (mutually exclusive)
perf-hashSwaps HashMap hasher to ahash::RandomState for better throughput
aotEnables src/aot/ cooked binary cache and AAM::load fast-path
ffi / python / jni / csharpEnables language binding surfaces
parallelEnables parallel parse-task pre-validation in pipeline
serdeDerives Serialize/Deserialize on SchemaInfo, AAMBuilder, etc.

AAM​

The main entry point for all AAM operations. AAM holds the parsed key-value map, registered type definitions, and schema definitions. All directives (@derive, @schema, @import, @type) are processed automatically at parse time.

Constructors​

AAM::new​

Creates a new, empty AAM instance.

use aam_rs::aam::AAM;

let cfg = AAM::new();
from aam_py import AAM

cfg = AAM()

AAM::parse​

Parses an AAM string and returns a new, fully populated AAM instance. If the string is a path to an existing file, it reads and parses the file with full source-directory support.

ParameterTypeDescription
content&strAAM source text to parse (or file path).

Returns: Result<AAM, Vec<AamlError>>

use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost\nport = 8080").unwrap();
assert_eq!(cfg.get("host").unwrap(), "localhost");
from aam_py import AAM

cfg = AAM.parse("host = localhost\nport = 8080")
assert cfg.get("host") == "localhost"

AAM::load​

Reads an AAM file from disk and returns a new AAM instance. With the aot feature (default), this uses a cooked .aam.bin cache as the primary path for zero-copy memory-mapped loading.

ParameterTypeDescription
file_pathimpl AsRef<Path>Path to the .aam file.

Returns: Result<AAM, Vec<AamlError>>

use aam_rs::aam::AAM;

let cfg = AAM::load("config.aam").unwrap();
println!("{}", cfg.get("host").unwrap());
from aam_py import AAM

cfg = AAM.load("config.aam")
print(cfg.get("host"))

AAM::from_pipeline​

Creates an AAM instance from a custom configured Pipeline. Use this if you need to register custom commands, parsers, or validators before parsing.

ParameterTypeDescription
pipeline&PipelineConfigured pipeline instance.
text&strAAM source text (or file path).

Returns: Result<AAM, Vec<AamlError>>

use aam_rs::aam::AAM;
use aam_rs::pipeline::{Pipeline, DefaultLexer, DefaultParser};

let pipeline = Pipeline::new();
let cfg = AAM::from_pipeline(&pipeline, "key = value").unwrap();

Lookup​

These methods retrieve values from the parsed key-value map.

get​

Retrieves a value by its key. Performs a simple O(1) forward lookup — no automatic fallback.

ParameterTypeDescription
key&strKey to find.

Returns: Option<&str>

use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost").unwrap();

assert_eq!(cfg.get("host").unwrap(), "localhost");
assert!(cfg.get("unknown").is_none());
from aam_py import AAM

cfg = AAM.parse("host = localhost")
assert cfg.get("host") == "localhost"
assert cfg.get("unknown") is None

reverse_search​

Finds all keys whose mapped value equals the given value.

ParameterTypeDescription
value&strValue to search for.

Returns: Vec<&str>

use aam_rs::aam::AAM;

let cfg = AAM::parse("a = x\nb = y\nc = x").unwrap();
let keys = cfg.reverse_search("x");
assert_eq!(keys, vec!["a", "c"]);
from aam_py import AAM

cfg = AAM.parse("a = x\nb = y\nc = x")
keys = cfg.reverse_search("x")
assert keys == ["a", "c"]

deep_search​

Finds all key-value pairs where the key contains the given pattern (substring match).

ParameterTypeDescription
pattern&strSubstring to search for in keys.

Returns: Vec<(&str, &str)>

use aam_rs::aam::AAM;

let cfg = AAM::parse("app_host = localhost\napp_port = 8080\ndbg = true").unwrap();
let pairs = cfg.deep_search("app_");
assert_eq!(pairs.len(), 2);
from aam_py import AAM

cfg = AAM.parse("app_host = localhost\napp_port = 8080\ndbg = true")
pairs = cfg.deep_search("app_")
assert len(pairs) == 2

find​

Combined key-value search. First tries an O(1) forward lookup by key; if the key does not exist, falls back to an O(N) value scan. Returns all matching pairs.

ParameterTypeDescription
query&strKey to find; fallback value match.

Returns: Vec<(&str, &str)>

use aam_rs::aam::AAM;

let cfg = AAM::parse("a = b\nx = y").unwrap();

// Key exists → O(1) lookup
let result = cfg.find("a");
assert_eq!(result, vec![("a", "b")]);

// Key missing → value scan
let result = cfg.find("y");
assert_eq!(result, vec![("x", "y")]);
from aam_py import AAM

cfg = AAM.parse("a = b\nx = y")

# Key exists → direct lookup
result = cfg.find("a")
assert result == {"a": "b"}

# Key missing → value scan
result = cfg.find("y")
assert result == {"x": "y"}

find_by​

Advanced search using a custom predicate function. Iterates over all pairs and returns those for which the predicate returns true.

ParameterTypeDescription
predicateimpl Fn(&str, &str) -> boolCustom match function.

Returns: Vec<(&str, &str)>

use aam_rs::aam::AAM;

let cfg = AAM::parse("host = localhost\nport = 8080\nversion = 3").unwrap();

// Find all pairs where the value starts with "8"
let pairs = cfg.find_by(|_key, value| value.starts_with('8'));
assert_eq!(pairs, vec![("port", "8080")]);

iter​

Iterates over all key-value pairs without allocating. Supports both dynamic HashMap and memory-mapped AOT backends.

Returns: Box<dyn Iterator<Item = (&str, &str)>>

use aam_rs::aam::AAM;

let cfg = AAM::parse("a = 1\nb = 2").unwrap();
for (key, value) in cfg.iter() {
    println!("{key} = {value}");
}

keys​

Returns all keys currently stored. Prefer iter for zero-allocation iteration.

Returns: Vec<&str>

use aam_rs::aam::AAM;

let cfg = AAM::parse("a = 1\nb = 2").unwrap();
for key in cfg.keys() {
    println!("{key}");
}
from aam_py import AAM

cfg = AAM.parse("a = 1\nb = 2")
for key in cfg.keys():
    print(key)

to_map​

Returns all key-value pairs as a standard allocated map. Prefer iter for zero-allocation iteration.

Returns: HashMap<String, String>

use aam_rs::aam::AAM;

let cfg = AAM::parse("a = 1\nb = 2").unwrap();
let map = cfg.to_map();
assert_eq!(map.get("a").unwrap(), "1");
from aam_py import AAM

cfg = AAM.parse("a = 1\nb = 2")
d = cfg.to_dict()
assert d == {"a": "1", "b": "2"}

Schema & Type Accessors​

These methods provide read-only access to the schemas and types discovered during parsing. They return None when the configuration was loaded via an AOT memory map (zero-copy mode).

schemas​

Returns a reference to all registered schemas.

Returns: Option<&HashMap<SmolStr, SchemaInfo>>

use aam_rs::aam::AAM;

let cfg = AAM::parse("@schema Player { name: string, id: i32 }").unwrap();
if let Some(schemas) = cfg.schemas() {
    for (name, info) in schemas {
        println!("Schema: {name}");
    }
}
from aam_py import AAM

cfg = AAM.parse("@schema Player { name: string, id: i32 }")
for name in cfg.schema_names():
    print(name)

get_schema​

Returns the schema registered under name, or None.

ParameterTypeDescription
name&strSchema name to look up.

Returns: Option<&SchemaInfo>

use aam_rs::aam::AAM;

let cfg = AAM::parse("@schema Player { name: string, id: i32 }").unwrap();
let schema = cfg.get_schema("Player").unwrap();
println!("{:?}", schema.fields);

types​

Returns a reference to all registered types.

Returns: Option<&HashMap<SmolStr, TypeInfo>>

use aam_rs::aam::AAM;

let cfg = AAM::parse("@type pos = math::vector3").unwrap();
if let Some(types) = cfg.types() {
    for (name, info) in types {
        println!("Type: {name} -> {}", info.spec);
    }
}
from aam_py import AAM

cfg = AAM.parse("@type pos = math::vector3")
for name in cfg.type_names():
    print(name)

get_type​

Returns the type info registered under name, or None.

ParameterTypeDescription
name&strThe registered type name.

Returns: Option<&TypeInfo>

use aam_rs::aam::AAM;

let cfg = AAM::new();
let info = cfg.get_type("i32");

Formatting​

These methods format AAM content using the parser + pipeline formatter.

format​

Parses and formats arbitrary AAM content. Returns the formatted string on success.

ParameterTypeDescription
content&strAAM source to format.
options&FormattingOptionsFormatting rules.

Returns: Result<String, AamlError>

use aam_rs::aam::AAM;
use aam_rs::pipeline::formatter::FormattingOptions;

let cfg = AAM::new();
let formatted = cfg.format("key=value", &FormattingOptions::default()).unwrap();
assert_eq!(formatted, "key = value\n");
from aam_py import AAM

cfg = AAM()
formatted = cfg.format("key=value")
assert formatted == "key = value\n"

format_range​

Formats only a selected line range of arbitrary AAM content.

ParameterTypeDescription
content&strAAM source to format.
rangeFormatRangeLine range to format.
options&FormattingOptionsFormatting rules.

Returns: Result<String, AamlError>

use aam_rs::aam::AAM;
use aam_rs::pipeline::formatter::{FormatRange, FormattingOptions};

let cfg = AAM::new();
let range = FormatRange { start_line: 1, end_line: 2 };
let result = cfg.format_range("a = 1\nb = 2\nc = 3", range, &FormattingOptions::default());
from aam_py import AAM

cfg = AAM()
result = cfg.format_range("a = 1\nb = 2\nc = 3", 1, 2)

lsp_assist​

Convenience method for LSP servers: parses with error recovery and optional formatting result. Returns diagnostics plus the formatted output (if no errors).

ParameterTypeDescription
content&strAAM source to process.
options&FormattingOptionsFormatting rules.

Returns: AamLspAssist

use aam_rs::aam::AAM;
use aam_rs::pipeline::formatter::FormattingOptions;

let result = AAM::lsp_assist("key=value", &FormattingOptions::default());
for diag in &result.diagnostics {
    eprintln!("{diag}");
}
if let Some(formatted) = &result.formatted {
    println!("{formatted}");
}
from aam_py import AAM

diagnostics, formatted = AAM.lsp_assist("key=value")
for d in diagnostics:
    print(d)

AamLspAssist​

The return type of AAM::lsp_assist. Contains diagnostics and optional formatted output.

pub struct AamLspAssist {
    pub diagnostics: Vec<AamlError>,
    pub formatted: Option<String>,
}

SchemaInfo​

The type returned by AAM::get_schema and contained in the map from AAM::schemas. Represents a parsed @schema definition.

Fields​

FieldTypeDescription
nameSmolStrSchema name.
fieldsHashMap<SmolStr, (SmolStr, bool)>Maps field names to (type_name, is_optional).
lineusizeSource line where the schema was defined.
use aam_rs::aam::AAM;

let cfg = AAM::parse("@schema Player { name: string, id*: i32 }").unwrap();
let schema = cfg.get_schema("Player").unwrap();

for (field_name, (type_name, is_optional)) in &schema.fields {
    println!("{field_name}: {type_name} (optional={is_optional})");
}

TypeInfo​

The type returned by AAM::get_type. Represents a registered type alias.

Fields​

FieldTypeDescription
nameSmolStrType name.
specSmolStrType specification (e.g. "i32", "math::vector3").
validatorOption<SmolStr>Optional custom validation rule.

AamlError​

All errors produced by the parsing and validation pipeline implement std::error::Error and Display.

Variants​

VariantDescription
IoError { details, diagnostics }I/O error while reading a file.
ParseError { line, content, details, diagnostics }Line could not be parsed as a valid AAM statement.
NotFound { key, context, diagnostics }Key or type not found.
InvalidValue { details, expected, diagnostics }Value fails a basic type constraint.
InvalidType { type_name, details, provided, diagnostics }Value fails validation against a registered/built-in type.
DirectiveError { directive, message, diagnostics }Directive encountered invalid arguments.
SchemaValidationError { schema, field, type_name, details, diagnostics }Schema constraint violated during parsing.
MissingRequiredField { schema, field, field_type, diagnostics }Required schema field is missing.
CircularDependency { path, diagnostics }Circular import or derivation detected.
TypeRegistrationConflict { type_name, existing, new, diagnostics }Type name registered with conflicting definitions.
NestingDepthExceeded { depth, context, diagnostics }Recursion depth limit exceeded.
MalformedLiteral { literal_type, content, diagnostics }Malformed inline object or array literal.
DirectiveSyntaxError { directive, provided_syntax, expected_syntax, diagnostics }Directive syntax is incorrect.
TypeConversionError { from_type, to_type, value, diagnostics }Type conversion failed.
LexErrorLexical analysis error.

Error Handling Example​

use aam_rs::aam::AAM;
use aam_rs::error::AamlError;

match AAM::load("config.aam") {
    Ok(cfg) => println!("Loaded successfully"),
    Err(errors) => {
        for err in &errors {
            match err {
                AamlError::IoError { details, .. } => {
                    eprintln!("Could not read file: {details}");
                }
                AamlError::ParseError { line, content, details, .. } => {
                    eprintln!("Parse error at line {line}: '{content}' — {details}");
                }
                AamlError::SchemaValidationError { schema, field, type_name, details, .. } => {
                    eprintln!("Schema '{schema}': field '{field}' ({type_name}) — {details}");
                }
                _ => eprintln!("Error: {err}"),
            }
        }
    }
}
from aam_py import AAM, AamlError

try:
    cfg = AAM.load("config.aam")
except AamlError as e:
    print(f"Error: {e}")

FoundValue​

A standalone utility type for working with AAM string values. Note: The AAM::get method returns Option<&str> directly, not FoundValue. Use FoundValue when you need list/object parsing helpers on raw strings.

FoundValue::new​

ParameterTypeDescription
value&strThe raw string.

Returns: FoundValue

use aam_rs::found_value::FoundValue;

let v = FoundValue::new("hello");
assert_eq!(v.as_str(), "hello");
from aam_py import FoundValue  # if available in your binding

v = FoundValue("hello")
assert str(v) == "hello"

Methods​

MethodDescription
as_str() -> &strReturns the inner value as a string slice.
as_list() -> Option<Vec<String>>Parses as [item, item, ...] list.
as_object() -> Option<HashMap<String, String>>Parses as { k = v, ... } inline object.
is_list() -> boolReturns true if value is a list literal.
is_object() -> boolReturns true if value is an inline object literal.
remove(target: &str) -> &mut SelfRemoves all occurrences of target from the value.
use aam_rs::found_value::FoundValue;

let v = FoundValue::new("[rust, aam, config]");
let items = v.as_list().unwrap();
assert_eq!(items, vec!["rust", "aam", "config"]);

let v = FoundValue::new("{ x = 1.0, y = 2.0 }");
let map = v.as_object().unwrap();
assert_eq!(map["x"], "1.0");
from aam_py import FoundValue

v = FoundValue("[rust, aam, config]")
items = v.as_list()
assert items == ["rust", "aam", "config"]
